# AI Export Sales Network — MVP

سیستم عملیاتی فروش صادراتی B2B با هوش مصنوعی.

مسیر اصلی: محصول → بازار → خریدار → اعتبارسنجی → تطبیق → ارتباط → پیگیری → RFQ → معامله → سفارش تکراری.

قیمت نهایی، پیشنهاد تجاری الزام‌آور، قرارداد، پرداخت و استثناهای حقوقی/Compliance فقط با تأیید انسان انجام می‌شوند.

در Production استفاده از PostgreSQL و ADMIN_TOKEN قوی الزامی است. ایمیل به‌صورت پیش‌فرض فقط Draft است.
